# Mechanical Keyboard

This mechanical keyboard uses tactile Brown switches with a 50-million-keystroke lifespan. It includes per-key RGB backlighting and a detachable USB-C cable.

The keyboard supports N-key rollover and anti-ghosting, making it suitable for both typing and gaming. Software is available for Windows and macOS to customize lighting and macros.

Dimensions are 440mm x 135mm x 35mm and the keyboard weighs 980 grams. A two-year warranty covers manufacturing defects.
